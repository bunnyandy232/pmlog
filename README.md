# PMLog

技术部门工作日志与项目管理原型（静态 HTML）。

## 本地打开

用浏览器打开：

- `prototypes/index.html`（登录选人入口）
- 或仓库根目录 `index.html`（自动跳转到原型）

## 在线部署（Vercel）

1. 将本仓库导入 [Vercel](https://vercel.com/new)
2. Framework Preset 选 **Other**，无需 Build Command
3. 部署后访问根路径即可进入登录页

也可安装 Vercel CLI 后在本目录执行：

```bash
npx vercel
```
